## 1. 系统概述

本系统由三部分组成：

| 部件 | 作用 |
| --- | --- |
| PX4 飞控（CUAV V6X） | 姿态/位置控制、解锁、模式管理 |
| MyLink 串口桥（`mylink_bridge`） | 独占 TELEM2 串口，解析WiFi上位机的 MAVLink 控制数据 |
| 激光串口桥（`top_distance_bridge`） | 独占 TELEM1 串口，接收单片机融合后的四路激光数据 |
| 上位机 | 通过 MAVLink 发送 Offboard 控制指令（位置/速度） |

典型使用方式：**解锁 → 切换到 Offboard 模式 → 上位机接管 → 结束降落**。整个过程中遥控器保持不动，仅在紧急情况下介入。

## 2. 通信链路

- **控制链路**：`mylink_bridge` 独占 TELEM2（`/dev/ttyS4`），波特率115200，连接WiFi模块和上位机。
- **激光链路**：`top_distance_bridge` 独占 TELEM1（`/dev/ttyS6`），波特率115200，连接融合四路测距的单片机。
- **上位机 → 飞控**：只通过TELEM2发送控制消息，不发送激光数据。
- **飞控 → 上位机距离监控**：飞控把统一的`top_distance`四路结果合并在一个MAVLink帧中，通过TELEM2/WiFi以最高10Hz发送；上位机按左上、右上、左下、右下显示，单位mm。
- **飞控 → 上位机电机监控**：CUAV V6X读取物理输出层`actuator_outputs`中的PWM脉宽，并按当前映射`MAIN1=M4、MAIN2=M3、MAIN3=M1、MAIN4=M2`重排为M1～M4；四路数据合并在一个MAVLink帧中，以最高10Hz发送。上位机显示实际PWM指令，单位μs；超过0.5秒没有新数据时显示`—`并变灰。WSL仿真没有物理PWM引脚，因此显示1000～2000μs的等效命令。
- **飞控 → 上位机触顶状态**：飞控把`SEARCH_TOP`、`TOP_APPROACH`、`CONTACT_VERIFY`、`CONTACT_PRESS`及退出原因以约2Hz周期发送。上位机分别显示“正在寻顶”“已发现顶部，缓慢靠近”“正在验证接触稳定”“触顶成功，正在增加贴顶压力”；超过1.5秒没有新状态时提示状态数据中断。首次指令ACK只表示寻顶已启动，不表示已经找到顶部。
- **WSL仿真距离监控**：Gazebo四个测距传感器直接进入飞控`top_distance`，再由`mylink_bridge`通过UDP 14541发给WSL上位机，不需要运行额外的激光转发脚本。
- **USB MAVLink**：保留给 QGC（地面站），用于解锁、切模式、手动接管和监控。

> 上位机的M1～M4是飞控输出层准备发送的PWM脉宽指令，不是真实转速RPM，也不能证明电调已收到该脉冲。要显示真实RPM，必须由支持转速遥测的电调或独立转速传感器提供反馈。

固件当前支持的上行消息：

| 消息 | 行为 |
| --- | --- |
| `PING` | 回显 PING 应答 |
| `SET_POSITION_TARGET_LOCAL_NED` | 预热 Offboard；进入 Offboard 后发布轨迹设定点 |
| `COMMAND_LONG` (`DO_SET_MODE`) | 请求进入 Offboard 模式（custom main mode = 6） |
| `COMMAND_LONG` (`NAV_LAND`) | 转发降落指令 |

> ⚠️ 电机测试（`MAV_CMD_DO_MOTOR_TEST`）和 event flag 记录当前**尚未在固件中接线**，上位机发送相关指令会被拒绝（`MAV_RESULT_DENIED` / `UNSUPPORTED`），请勿依赖。

## 3. 解锁与油门位置规范

解锁时飞控会检查油门杆位置是否安全，**按当前飞行模式区分**：

| 解锁时所在模式 | 油门要求 | 50% 油门能否解锁 |
| --- | --- | --- |
| 手动 / 自稳 / 特技 | 油门杆在**最底**（`<-0.8`） | ❌ 拒绝 |
| 定高 / 位置 | 油门杆在**中位或以下**（`<=0.2`） | ✅ 允许 |
| Offboard / 自动 | 跳过油门检查 | ✅ 允许 |

**要点**：

- 油门杆中位（50%）= 爬升率 0 = 悬停；**只有在手动/自稳/特技模式下油门才对应直接推力**。
- 因此"50% 油门解锁导致快速起飞"的情况**在正常流程下不会发生**：能解锁成功的 50% 油门一定落在"中位=悬停"的模式里，而"50%=50% 推力"的手动模式会拒绝解锁。
- **例外**：解锁后 5 秒内再次用遥控开关解锁会跳过预检（为"空中误断电快速复电"设计）。地面正常解锁不受影响。

## 4. 标准操作流程

1. **上电自检**：等待飞控初始化完成、GPS/位置估计可用。
2. **解锁**：确认油门杆位置符合上表要求后解锁。
3. **预热 Offboard 数据流**：上位机开始持续发送 `SET_POSITION_TARGET_LOCAL_NED`（进入 Offboard 前**至少预热 1 秒**）。
4. **切入 Offboard**：通过遥控器模式开关或上位机 `DO_SET_MODE` 进入 Offboard 模式。
5. **上位机接管**：进入 Offboard 后，设定点开始真正驱动飞机。
   - 发送频率 **≥ 2 Hz，建议 20 Hz**。
   - 整个飞行过程**必须持续发送**，不能停。
6. **结束**：任务完成后发送降落指令，或先切回手动/位置模式再人工降落。

> Offboard 数据流一旦停止，飞控会在正常的 Offboard 丢失超时后自动退出 Offboard（安全机制，桥模块不会重放旧的设定点）。

## 5. 紧急接管（遥控器）

突发状况下直接拨遥控器摇杆即可夺回控制，但**注意接管后的模式**：

- 接管触发后，飞控切换到 **位置模式（Position）**，位置不可用时退到 **定高模式（Altitude）**——**不是手动/自稳模式**。
- 位置模式下油门杆是「爬升率命令」，**中位=悬停**，不是直接推力。

**触发条件**（不是"任意值改变"就触发）：

- 摇杆（横滚/俯仰/偏航/油门任一）的**移动速度**超过阈值 `MAN_OVERRIDE_SPD`（默认 `1.0`，即约 0.5 秒内拨过半程），且连续几拍同方向。
- 缓慢推杆、轻微抖动 **不会**触发。
- 将 `MAN_OVERRIDE_SPD` 设为**负数**可关闭该接管功能。

> 紧急接管时请预期：拨杆后进入的是**位置模式**（自动保持位置/定高），而非完全手动直推油门。如需完全手动控制，接管后还需通过模式开关再切到手动/自稳。

## 6. 关键参数速查

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `MLB_CONFIG` | `102`（TELEM2） | MyLink/WiFi控制桥占用串口 |
| `TDB_CONFIG` | `101`（TELEM1） | 四路激光接收桥占用串口 |
| `SER_TEL1_BAUD` | `115200` | TELEM1激光链路波特率 |
| `SER_TEL2_BAUD` | `115200` | TELEM2控制链路波特率 |
| `MAV_0_CONFIG` | `0` | 关闭默认TELEM1遥测实例，将TELEM1让给激光接收桥 |
| `MAN_OVERRIDE_SPD` | `1.0`（1/s） | 遥控接管触发阈值；负数关闭 |

## 7. 注意事项

1. **Offboard 下上位机必须持续发设定点**（≥2 Hz，建议 20 Hz），停止即触发 Offboard 丢失保护。
2. **进入 Offboard 前先预热数据流 ≥1 秒**，否则可能无法稳定切入。
3. **电机测试 / event flag 当前未启用**，上位机请勿依赖 `MAV_CMD_DO_MOTOR_TEST` 等指令。
4. **紧急接管进入的是位置模式**，不是手动模式，提前熟悉其手感（中位=悬停）。
5. USB 始终保留给 QGC，可用于监控和兜底操作。

## 8. 常见问题

**Q：解锁时 50% 油门会不会突然起飞？**
A：不会。手动/自稳模式会拒绝 50% 油门解锁；定高/位置模式 50%=中位=悬停。

**Q：Offboard 模式下拨遥控器为什么进的是位置模式而不是手动？**
A：这是 PX4 的固定接管行为（`sticks_moving` → 位置模式），非本桥模块可改。需要手动时接管后再切模式开关。

**Q：为什么轻轻碰一下摇杆没反应？**
A：接管需要摇杆**移动速度**超过 `MAN_OVERRIDE_SPD` 阈值，缓慢移动不触发。

**Q：数据流一停飞控就退出 Offboard 吗？**
A：是。桥模块故意不重放旧设定点，让 PX4 正常的 Offboard 丢失超时生效，属于安全设计。
